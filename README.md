# Spatial Modelling of Malaria Vector Abundance in Uganda

## Project overview

This repository contains R scripts and supporting materials for a research project on spatial modelling of malaria vector abundance in Uganda.

The project is being developed as part of doctoral research and is currently under development.

## Details

The repository contains scripts for:

- data cleaning and preparation;
- environmental covariate preparation;
- statistical modelling;
- model diagnostics;
- spatial prediction; and
- production of maps and other research outputs.

The modelling framework and interpretation of results are still being reviewed and should not be considered final.
