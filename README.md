This repository implements a spatial modelling workflow to estimate Anopheles gambiae s.l. abundance across Uganda using national entomological surveillance data.
It applies three nested Negative Binomial models (M1, M2 and M3) incorporating household, intervention, environmental, temporal, sampling-intensity and site-level effects.
The integrated M3 model incorporates a validated continental ecological prediction surface to support national-scale abundance estimation.
The workflow includes data cleaning, quality assurance, spatial covariate preparation, model fitting, DHARMa diagnostics and standardized 1 × 1 km spatial predictions.
The resulting maps, model outputs and diagnostics aim to support evidence-based malaria vector surveillance, control planning and operational decision-making in Uganda.
